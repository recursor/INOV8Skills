## Tag legend

Use bracket tags as content is added so synthesis can filter quickly.

- `[STEP]` — a procedural step
- `[DECISION]` — a fork in the process with criteria
- `[EXCEPTION]` — a non-routine case that requires deviation
- `[WORKAROUND]` — an unwritten rule, system workaround, or off-procedure tactic that is load-bearing in practice
- `[TOOL]` — a system, application, or document the SME uses
- `[GAP]` — an unresolved point that needs an answer before the deliverable ships
- `[CONFIRM]` — a tentative answer that needs verification (e.g., from another SME or via observation)
